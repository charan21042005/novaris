## 📌 Directory Purpose

The **`/assets`** directory centralizes all official visual graphics, banners, and icons embedded across the NOVARIS repository documentation. Vector graphics ensure crisp, artifact-free rendering across high-DPI (Retina) displays, GitHub light/dark themes, and mobile screens.
